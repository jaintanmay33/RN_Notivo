# Notivo — Advanced Todo App

A production-grade todo application built with React Native and Expo.

## Features

- 📝 Create, edit, and archive todos with rich metadata
- 🗂 Tab-based filtering (All, Active, In Progress, Done, Archived)
- 📋 Kanban board with drag-and-drop
- 📊 Reporting dashboard with charts and drill-down
- 🎨 Light and Dark mode (Violet-Amber theme)
- 🌐 4 languages: English, Spanish, French, Arabic
- 🔔 Local push notifications for reminders

## Tech Stack

React Native · Expo · TypeScript · Zustand · Reanimated v3 · Victory Native
